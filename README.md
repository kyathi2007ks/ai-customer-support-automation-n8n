# AI-Powered Customer Support Email Automation

An AI-powered customer support email automation workflow built using **n8n** and **Google Gemini**.

## 🚀 Overview

This project automates the process of handling customer support emails using AI.

The workflow receives incoming emails, identifies whether they are customer-support related, and uses an AI Agent powered by Google Gemini to generate an appropriate response.

## 🔄 Workflow

Gmail Trigger → Text Classifier → AI Agent → Gmail Reply

### Workflow Components

- **Gmail Trigger** – Detects incoming emails
- **Text Classifier** – Identifies customer-support emails
- **Google Gemini** – Provides AI-powered understanding and response generation
- **AI Agent** – Generates an appropriate customer response
- **Gmail** – Sends the generated response
